## Tentang Map Hard Cover

Map hard cover adalah map dokumen premium dengan sampul tebal yang dilapisi kertas premium. Cocok untuk map raport, map sertifikat, map ijazah, atau map proposal tender. Kantong mika bening di dalamnya memudahkan penyimpanan dokumen tanpa melubangi.

## Keunggulan Layanan Kami

- **Hard cover tebal** — Sampul kokoh, awet untuk jangka panjang
- **Kantong mika bening** — Memasukkan dokumen tanpa perlu jilid
- **Embos emas / silver** — Logo dan nama dengan finishing premium
- **Custom desain** — Layout sesuai identitas sekolah/perusahaan
- **Berbagai ukuran** — A4 folio atau custom

## Proses Pengerjaan

1. Konsultasi ukuran, jumlah, dan desain map yang diinginkan oleh klien.
2. Persiapan file untuk proses embos emas atau silver dan cetak cover.
3. Produksi hard cover dari karton tebal dengan laminasi premium.
4. Pemasangan kantong mika bening di bagian dalam map secara presisi.
5. Proses embos logo dan teks dengan mesin tekanan tinggi untuk hasil timbul.
6. Quality control hasil embos, kelengkapan kantong, dan kerapihan map sebelum packing.

## Aplikasi Umum

- Map raport sekolah (Kurikulum Merdeka)
- Map sertifikat dan ijazah
- Map proposal tender
- Map dokumen perusahaan
- Map kelulusan universitas
- Map MOU dan kontrak

## FAQ

**Berapa minimal order?**
Standar 50 pcs. Untuk order kecil, harga lebih tinggi.

**Apa itu embos emas?**
Teknik cetak dengan tekanan tinggi untuk menampilkan logo/nama dalam warna emas metalik (atau silver). Hasil premium dan tahan lama.

**Berapa ukuran standar?**
Folio (22×33 cm) untuk map raport. Custom sesuai kebutuhan.

**Apakah bisa desain map sendiri?**
Bisa. Kami terima file desain format PDF, CDR, atau AI dan siap produksi.

**Berapa lama proses pengerjaan?**
Standar 3–7 hari kerja untuk 50–200 pcs, tergantung kerumitan embos.

**Apakah bisa dikirim ke luar kota?**
Bisa. Kami kirim ke seluruh Palembang dan Sumatera Selatan via ekspedisi dengan packing aman.
